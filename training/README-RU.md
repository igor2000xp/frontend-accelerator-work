# Обучение Frontend Accelerator

В этой директории содержатся все учебные задания и материалы для оценки. Она отделена от документации по установке инструментария, среде выполнения, агентам, навыкам и наборам правил.

Если ментор явно не назначил **Advanced / Production Assessment**, проходите только **Basic Accelerator Onboarding**.

## Использование учебного пакета

Скопируйте только назначенную директорию пакета в корень целевого проекта и сохраните имя этой директории неизменным. Не копируйте родительскую директорию `training/` или второй трек.

## Выберите один трек

### По умолчанию: Basic Accelerator Onboarding

Используйте [`frontend-accelerator-onboarding/README.md`](https://www.google.com/search?q=frontend-accelerator-onboarding/README.md).

Выбирайте этот трек, когда цель — научиться:

* вручную выбирать роли акселератора;
* писать сфокусированные, четко ограниченные промпты для каждой выбранной роли;
* проверять результаты работы каждой роли;
* определять следующее действие без автоматической цепочки ролей;
* проходить один небольшой цикл разработки, ревью и верификации;
* фиксировать достоверные и лаконичные доказательства выполненной работы (evidence).

Результат бинарный: **Passed** (Сдано) или **Repeat a stage** (Повторить этап). Доработка до идеального продакшен-уровня не требуется.

### Только по назначению: Advanced / Production Assessment

Используйте [`frontend-accelerator-assessment/README.md`](https://www.google.com/search?q=frontend-accelerator-assessment/README.md) только в том случае, если ментор явно назначил этот трек.

Этот трек оценивает как использование акселератора, так и качество фронтенда с точки зрения продакшен-стандартов. Он включает 100-балльную систему оценки, минимальные пороги по разделам, блокеры оценки, расширенные проверки в браузерах и более строгие продуктовые требования. Он не является обязательным условием для завершения Basic Accelerator Onboarding.
